# WaveRider

WaveRider is a noir-inspired interface for an ML toolkit suite:

- WavePeak — Feature Extraction Audio Classifier
- WaveVis — Machine Learning Data Visualization Tool
- WaveTrainer — Raspberry Pi Model Trainer
- WavePCB — PCB designer visual tool
- WaveTorch — Torch Tensorboard Visualizer
- WaveChat — Finetune & Train ChatBots
- WaveBoost — Lightweight ML Optimization Library
- WaveGen — Rapid Model Prototyping Utility

## Run locally

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.
